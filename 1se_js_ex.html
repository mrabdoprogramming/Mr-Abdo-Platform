🛠️ أولًا: تجهيز بيئة العمل

هنستخدم Visual Studio Code لكتابة الكود. لكن قبل ما نبدأ، هنضيف مجموعة من الإضافات Extensions تساعدنا أثناء البرمجة.

1. Prettier

Code Formatter

Prettier هو Code Formatter — يعني أداة تقوم بتنسيق الكود تلقائيًا بطريقة موحدة ومنظمة.

قبل Prettier
let name="Abdo";
console.log(name);
بعد Prettier
let name = "Abdo";
console.log(name);
أهميته: لما يكون عندك 100 أو 1000 سطر من الكود، التنظيم يصبح مهم جدًا. كما أنه يساعد الفريق كله على كتابة الكود بنفس أسلوب التنسيق تقريبًا.

2. ESLint

Code Linter

ESLint مختلف عن Prettier. Prettier يهتم بشكل الكود وتنسيقه. أما ESLint فيقوم بفحص الكود واكتشاف بعض المشاكل والأخطاء والممارسات التي قد تؤدي إلى مشاكل.

تنبيه ESLint
let age = 20;

// ESLint: 'age' is declared but its value is never read.
مهم جدًا: ESLint ليس "لغة JavaScript" وليس هو الذي يجعل JavaScript تعمل. هو أداة تساعد المبرمج على كتابة كود أفضل.

3. Indent Rainbow

Visual Helper

Indentation معناها المسافات التي توضح مستويات الكود. في بعض اللغات والمشاريع، خصوصًا عندما يكون عندنا Blocks متداخلة، يكون من الصعب معرفة كل جزء تابع لأي جزء.

Indent Rainbow يقوم بتلوين مستويات الـ indentation بشكل يساعد العين على تتبعها.

هو ليس ضروريًا لتشغيل JavaScript، لكنه أداة مساعدة لفهم وترتيب الكود.

4. Live Server

Dev Server

Live Server يسمح لنا بتشغيل صفحات HTML على Local Development Server. بدل ما نفتح ملف HTML بشكل تقليدي، يمكننا تشغيل الصفحة من خلال سيرفر محلي، وعند تعديل الملفات يمكن رؤية التغييرات بسرعة.

هذا مفيد جدًا عندما نبدأ العمل على: HTML · CSS · JavaScript.

5. Material Icon Theme

File Icons

إضافة تجعل شكل الملفات والمجلدات داخل Visual Studio Code أوضح من خلال Icons مختلفة. مثلًا يمكن أن يظهر ملف HTML بأيقونة مختلفة عن CSS أو JavaScript.

هي لا تؤثر على الكود إطلاقًا. هي فقط لتحسين تجربة العمل داخل المحرر.

6. Path Intellisense

Path Autocomplete

تساعدنا أثناء كتابة مسارات الملفات. مثلًا عندما نريد ربط ملف JavaScript:

<script src="./js/script.js"></script>

الإضافة تساعدنا في اقتراح الملفات والمجلدات الموجودة بدل كتابة المسار كاملًا يدويًا.

📍 ثانيًا: أين نضع JavaScript داخل صفحة HTML؟

JavaScript يمكن إضافتها إلى صفحة HTML بعدة طرق. سنركز الآن على 3 أماكن أساسية:

🔹 الطريقة الأولى: داخل head

<!DOCTYPE html>
<html>
<head>

<script>
    console.log("Hello JavaScript");
</script>

</head>

<body>

<h1>Hello World</h1>

</body>
</html>

هنا JavaScript موجودة داخل عنصر script الموجود في head. لكن هناك مشكلة مهمة.

المشكلة

المتصفح يقرأ HTML بالترتيب. يعني عندما يصل إلى script، يمكن أن ينفذ JavaScript قبل أن يكون قد قرأ باقي عناصر HTML الموجودة بعده.

<head>

<script>
    let title = document.querySelector("h1");
    console.log(title);
</script>

</head>

<body>

<h1>Hello World</h1>

</body>
ما المشكلة؟

عندما JavaScript حاول البحث عن h1، فإن المتصفح لم يصل إلى h1 أصلًا. لذلك العنصر لم يكن موجودًا في الـ DOM في تلك اللحظة.

🔹 الطريقة الثانية: JavaScript في نهاية body

<!DOCTYPE html>
<html>

<head>
</head>

<body>

<h1 id="title">Hello World</h1>

<script>
    let title = document.querySelector("#title");
    console.log(title);
</script>

</body>

</html>

هنا المتصفح قرأ h1 أولًا. وبعدها وصل إلى JavaScript. لذلك العنصر أصبح موجودًا ويمكن الوصول إليه.

ميزة هذه الطريقة

هذه الطريقة كانت وما زالت طريقة بسيطة جدًا لتجنب مشكلة محاولة JavaScript الوصول إلى عناصر HTML قبل إنشائها في DOM.

🔹 الطريقة الثالثة: ملف JavaScript خارجي

بدل أن نكتب JavaScript داخل HTML، يمكننا إنشاء ملف:

index.html
script.js

وفي HTML:

<script src="script.js"></script>

وفي script.js:

console.log("Hello from JavaScript file");

بهذه الطريقة يصبح HTML مسؤولًا عن هيكل الصفحة، وJavaScript موجودة في ملف منفصل. وهذا أفضل لتنظيم المشاريع.

ميزة الملف الخارجي
  • يمكن إعادة استخدامه.
  • الكود يصبح أسهل في التنظيم.
  • HTML لا يصبح مليئًا بكود JavaScript.
  • يمكن فصل مسؤوليات المشروع.

🔹 طيب لو عايزين نحط ملف JavaScript في head؟

هنا عندنا حل مهم: defer

<script src="script.js" defer></script>

مع defer:

  • المتصفح يستطيع تحميل ملف JavaScript أثناء قراءة الصفحة، لكن تنفيذ السكربت يتم بعد الانتهاء من تحليل HTML.
  • وبالتالي نستطيع وضع ملف JavaScript في head مع تقليل مشكلة محاولة الوصول إلى عناصر HTML قبل وجودها.
  • والأهم أن defer يحافظ على ترتيب تنفيذ ملفات JavaScript المؤجلة حسب ترتيب ظهورها في الصفحة.

🔹 إيه الفرق بين defer و async؟

مش مطلوب نتعمق فيهم الآن، لكن لازم نعرف الفكرة.

defer

  • السكريبت يتم تحميله أثناء قراءة الصفحة، ثم يتم تنفيذه بعد تحليل HTML.
  • يحافظ على ترتيب تنفيذ السكربتات المؤجلة.

async

  • السكريبت يتم تحميله بشكل مستقل، وعندما ينتهي تحميله يتم تنفيذه.
  • لا نعتمد على ترتيب التنفيذ بين عدة async scripts.
// async — لا نفترض أن one.js سينفذ دائمًا قبل two.js
<script async src="one.js"></script>
<script async src="two.js"></script>

// defer — ترتيب التنفيذ حسب ترتيب ظهورهما
<script defer src="one.js"></script>
<script defer src="two.js"></script>

🔹 ماذا نستخدم في المشاريع الحديثة؟

  • في حالة ملف JavaScript خارجي عادي يعتمد على وجود عناصر HTML: <script src="script.js" defer></script> يعتبر اختيارًا ممتازًا.
  • كما أن وضع script في نهاية body يظل طريقة بسيطة ومفهومة جدًا، خصوصًا أثناء تعلم الأساسيات.
  • وفي المشاريع التي تستخدم JavaScript Modules: <script type="module" src="script.js"></script> — فالـ module scripts يتم التعامل معها بطريقة مختلفة، وتكون مؤجلة افتراضيًا.

🔹 طيب هل نستخدم window.onload؟

ممكن.

window.onload = function () {
    let title = document.querySelector("#title");
    console.log(title);
};

الفكرة هنا أن الكود ينتظر حدث load. لكن لازم نفرق بين: DOM أصبح جاهزًا و كل الصفحة والموارد أصبحت محملة.

حدث load ينتظر تحميل الصفحة ومواردها مثل الصور وغيرها. لو هدفنا فقط هو انتظار بناء HTML والـ DOM، فإن DOMContentLoaded أكثر تحديدًا لهذا الغرض.

document.addEventListener("DOMContentLoaded", function () {
    let title = document.querySelector("#title");
    console.log(title);
});

لكن لو استخدمنا defer مع ملف JavaScript خارجي، ففي حالات كثيرة لن نحتاج أصلًا إلى كتابة DOMContentLoaded.

قاعدة مهمة

لا تحفظ: "لازم دائمًا أستخدم window.onload."

احفظ: "لازم أفهم متى يتم تنفيذ JavaScript، وهل العناصر التي أريد التعامل معها أصبحت موجودة أم لا."

🔹 قاعدة مهمة جدًا

في مشاريعنا سنفضل غالبًا:

ملف JavaScript خارجي + defer 
<script src="./js/script.js" defer></script>

بدل الاعتماد على window.onload كحل لكل شيء.

🖥️ ثالثًا: ما هو Console؟

لما نفتح Developer Tools في المتصفح، سنجد تبويب اسمه Console. لكن ما هو الـ Console؟ هل هو جزء من JavaScript؟

الإجابة

لا. الـ console ليس جزءًا من لغة JavaScript الأساسية نفسها. في المتصفح، console عبارة عن Web API يوفرها المتصفح للمطور.

📌 ما معنى API؟

API اختصار: Application Programming Interface

بمعنى مبسط: واجهة أو مجموعة من الأدوات والقواعد التي تسمح لبرنامج بالتعامل مع وظيفة أو نظام معين بطريقة محددة.

🍽️

تخيل أن عندك مطعم. أنت كعميل لا تدخل المطبخ وتبدأ تطبخ بنفسك. أنت تتعامل مع الـ Menu وتطلب ما تحتاجه.

الـ Menu هنا تشبه فكرة الـ API. أنت تستخدم طريقة محددة للوصول إلى وظيفة معينة دون الحاجة لمعرفة كل التفاصيل الداخلية التي تنفذها.

📌 ما هو Web API؟

Web APIs هي مجموعة من الواجهات التي يوفرها بيئة الويب والمتصفح لكي يستطيع JavaScript التعامل مع إمكانيات مختلفة. مثل:

DOM API
Console API
Fetch API
Geolocation API
Web Storage API

JavaScript هي اللغة. لكن المتصفح يوفر لها أدوات إضافية لكي تتعامل مع البيئة المحيطة بها.

console.log("Hello");

هنا: console هو object يوفره بيئة المتصفح. log هي method نستطيع استدعاءها.

إذن console ليست "جزءًا من قواعد اللغة JavaScript"، وإنما المتصفح يوفرها لنا كواجهة للتعامل مع Developer Console.

مهم جدًا: لأن JavaScript نفسها يمكن أن تعمل في بيئات أخرى غير المتصفح، مثل Node.js، وهناك APIs وبيئة تشغيل مختلفة.

📌 ماذا نستطيع أن نفعل بالـ Console؟

أغلب الطلاب يعرفون console.log(). لكن Console ليست فقط لتسجيل الأخطاء. يمكن استخدامها في:

  • عرض قيم المتغيرات.
  • فحص نتائج العمليات.
  • تتبع خطوات تنفيذ البرنامج.
  • اكتشاف مكان المشكلة.
  • عرض التحذيرات.
  • عرض الأخطاء.
  • عمل Counters.
  • عمل Timers.
  • عرض معلومات منظمة.
  • التعامل مع بعض الكائنات أثناء Debugging.

📌 أهم الدوال التي سنعرفها

console.log()

لطباعة معلومات عادية.

let name = "Abdo";
console.log(name);
Console Output:
Abdo

console.error()

لعرض رسالة كخطأ.

console.error("Something went wrong");

console.warn()

لعرض تحذير.

console.warn("Be careful!");

console.table()

مفيد جدًا مع البيانات المنظمة والمصفوفات والكائنات.

let students = ["Ahmed", "Ali", "Omar"];
console.table(students);

بدل عرض البيانات بطريقة عادية، يمكن للمتصفح عرضها في شكل منظم.

console.clear()

تستخدم لمسح محتوى الـ Console.

console.count()

تساعدنا في معرفة عدد مرات تنفيذ نقطة معينة.

console.count("Button Clicked");

كل مرة يتم تنفيذ السطر سيزيد العداد.

console.time() و console.timeEnd()

يمكن استخدامهما لقياس الوقت الذي استغرقه جزء من الكود.

console.time("Test");

for (let i = 0; i < 100000; i++) {
    // some work
}

console.timeEnd("Test");
وهكذا نفهم أن Console أداة مهمة جدًا في Debugging وليس مجرد مكان تظهر فيه الأخطاء.

📜 رابعًا: ECMAScript و JavaScript

قبل ما نكتب JavaScript، لازم نعرف معلومة مهمة. JavaScript مرتبطة بمواصفة اسمها: ECMAScript

ECMAScript

المواصفة والمعيار.

JavaScript

واحدة من اللغات/التنفيذات التي تتبع هذا المعيار.

المواصفة يتم تطويرها من خلال Ecma International، ويعمل على تطوير معيار ECMAScript فريق TC39.

📌 ما هو ES6؟

ES6 هو اختصار: ECMAScript 6 — وهو الإصدار السادس من معيار ECMAScript. ويعرف أيضًا باسم: ECMAScript 2015 — لأنه صدر في عام 2015.

ومن الأشياء المشهورة التي جاءت مع ES6:

let
const
Arrow Functions
Template Literals
Destructuring
Default Parameters
Rest Parameters
Spread Syntax
Classes
Modules

إذن لما تسمع ES6 لا تفكر أنها لغة جديدة. هي نسخة/إصدار مهم من معيار ECMAScript.

let name = "Abdo";

const age = 23;

let و const من الميزات التي أصبحت جزءًا مهمًا من JavaScript الحديثة مع ES6.

💬 خامسًا: التعليقات Comments

أثناء كتابة الكود، أحيانًا نحتاج إلى كتابة ملاحظات داخل الملف. هذه الملاحظات لا يقوم JavaScript بتنفيذها. نسميها: Comments أو التعليقات.

📌 لماذا نستخدم Comments؟

  • لشرح فكرة معينة.
  • لتوضيح جزء معقد.
  • كتابة ملاحظات للمبرمجين الآخرين.
  • تعطيل سطر مؤقتًا أثناء تجربة شيء ما.
لكن لا يجب أن نضع Comment لكل سطر بلا سبب. الـ Comment الجيد يشرح "لماذا" نفعل شيئًا عندما يكون السبب غير واضح، وليس فقط يعيد وصف الكود حرفيًا.

📌 نوع التعليق الأول: Single-line Comment

يبدأ بـ: //

// This is a comment

let age = 20;

كل ما يأتي بعد // في نفس السطر يعتبر Comment.

let age = 20; // Student age

JavaScript ستنفذ: let age = 20; — أما // Student age فلن يتم تنفيذها.

📌 نوع التعليق الثاني: Multi-line Comment

يبدأ بـ: /* وينتهي بـ: */

/*
    This is a multi-line comment.
    It can contain multiple lines.
*/

let name = "Abdo";

يمكن استخدامه عندما نحتاج إلى كتابة تعليق يمتد لأكثر من سطر.

📌 مثال عملي

let price = 100;

// Apply discount

let discount = 20;

let finalPrice = price - discount;

هنا التعليق يساعدنا على فهم وظيفة الجزء التالي.

📦 سادسًا: نبدأ JavaScript فعليًا

الآن أصبح عندنا الأساس الذي نحتاجه. نعرف: أين نكتب JavaScript. كيف نربط JavaScript بـ HTML. ما هو Console. ما معنى Web API. ما هو ECMAScript. ما معنى ES6. كيف نكتب Comments.

والآن نبدأ مراجعة أساسيات اللغة.

📌 ما هي JavaScript؟

JavaScript هي لغة برمجة تستخدم لإضافة السلوك والتفاعل إلى صفحات وتطبيقات الويب، ويمكن استخدامها أيضًا خارج المتصفح في بيئات تشغيل أخرى.

HTML

هيكل الصفحة.

CSS

شكل وتصميم الصفحة.

JavaScript

السلوك والتفاعل والمنطق.

مثال:
HTML يقول: عندي Button.
CSS يقول: الـ Button شكله أزرق.
JavaScript تقول: عندما يضغط المستخدم على الـ Button، نفذ شيئًا معينًا.

📌 Variables (المتغيرات)

المتغير Variable هو مكان منطقي نستخدمه لتخزين قيمة يمكن للبرنامج التعامل معها.

let studentName = "Ahmed";

هنا: studentName اسم المتغير. و "Ahmed" القيمة المخزنة.

لماذا نحتاج Variables؟

لأننا لا نريد أن نكتب نفس القيمة يدويًا في كل مكان.

مثال سيئ
console.log("Ahmed");
console.log("Ahmed");
console.log("Ahmed");
الأفضل
let name = "Ahmed";

console.log(name);
console.log(name);
console.log(name);

إذا تغير الاسم، نغير القيمة في مكان واحد.

let

نستخدم let عندما نريد إنشاء متغير يمكن تغيير قيمته.

let age = 16;

age = 17;

console.log(age);
Console Output:
17

const

نستخدم const عندما لا نريد إعادة إسناد قيمة جديدة للمتغير.

const birthYear = 2010;

birthYear = 2011; // ❌ Error
خطأ

هذا سيؤدي إلى Error لأننا حاولنا إعادة إسناد قيمة لمتغير const.

قاعدة بسيطة:
let — يمكن إعادة إسناد قيمة له.
const — لا يمكن إعادة إسناد قيمة جديدة له.
ملاحظة مهمة: const لا يعني أن كل شيء داخل القيمة أصبح "غير قابل للتغيير" في كل الحالات. لكن بالنسبة للمستوى الحالي، أهم شيء أن الطالب يفهم أن إعادة إسناد متغير const ممنوعة.

📌 قواعد تسمية المتغيرات

اسم المتغير يجب أن يكون واضحًا.

جيد

let studentName = "Ali";

سيئ

let x = "Ali";

إذا كان x يمثل اسم الطالب، فمن الأفضل: studentName.

يمكن استخدام: الحروف. الأرقام، لكن ليس في بداية الاسم. underscore: student_name. Dollar sign: $student.

// ❌ غير صحيح
let 1name = "Ali";

// ✅ صحيح
let name1 = "Ali";

🏷️ سابعًا: Data Types

نوع البيانات يعني نوع القيمة التي يتعامل معها البرنامج.

من أهم الأنواع التي سنراجعها: Number · String · Boolean

🔢 Number

الأرقام.

let age = 16;
let price = 99.5;

📝 String

النصوص.

let name = "Ahmed";
let city = "Damanhur";

✅ Boolean

قيمة من اثنتين: true أو false.

let isStudent = true;
let isGraduated = false;

📌 typeof

يمكننا استخدام typeof لمعرفة نوع القيمة.

let age = 16;
console.log(typeof age); // "number"

let name = "Ahmed";
console.log(typeof name); // "string"

let isStudent = true;
console.log(typeof isStudent); // "boolean"

🧮 ثامنًا: العمليات الحسابية

JavaScript تستطيع تنفيذ العمليات الحسابية.

+الجمع
-الطرح
*الضرب
/القسمة
let a = 10;
let b = 5;

console.log(a + b); // 15
console.log(a - b); // 5
console.log(a * b); // 50
console.log(a / b); // 2

مثال عملي

let price = 100;
let quantity = 3;

let total = price * quantity;

console.log(total); // 300

هنا استخدمنا Variables + Multiplication.

📌 دمج النصوص

يمكن استخدام + لدمج النصوص.

let firstName = "Ahmed";
let lastName = "Ali";

let fullName = firstName + " " + lastName;

console.log(fullName); // Ahmed Ali
انتبه

+ يمكن أن تستخدم للجمع أو لدمج النصوص حسب نوع البيانات.

console.log(10 + 5); // 15
console.log("10" + "5"); // "105" — لأننا نتعامل مع Strings

⚖️ تاسعًا: Comparison Operators

نستخدم Comparison Operators لمقارنة القيم. أهمها:

==يساوي
===يساوي تمامًا
!=لا يساوي
>أكبر من
<أصغر من
>=أكبر أو يساوي
<=أصغر أو يساوي

والنتيجة غالبًا تكون: true أو false.

==

يقارن القيمة مع السماح بتحويل النوع في بعض الحالات.

5 == "5" // true

===

يقارن القيمة والنوع.

5 === "5" // false
// لأن 5 → Number، و "5" → String
كقاعدة عملية: يفضل في JavaScript الحديثة استخدام === و !== عندما نريد مقارنة صارمة وواضحة.

📌 Logical Operators

لدينا ثلاثة عوامل منطقية أساسية: && · || · !

AND — &&

كل الشروط يجب أن تكون صحيحة.

let age = 16;
let hasCard = true;

console.log(age >= 15 && hasCard === true);

OR — ||

يكفي تحقق شرط واحد على الأقل.

let hasMoney = false;
let hasCard = true;

console.log(hasMoney || hasCard); // true

NOT — !

تعكس القيمة المنطقية.

let isStudent = true;

console.log(!isStudent); // false

📌 Input و Output

نريد أحيانًا استقبال بيانات من المستخدم. من الطرق البسيطة في المتصفح: prompt()

let name = prompt("Enter your name:");
console.log(name);

هنا المستخدم يدخل قيمة، ونخزنها في المتغير name.

Output: يمكننا عرض النتائج باستخدام console.log() ويمكننا أيضًا استخدام alert().

alert("Welcome!");

لكن في تدريبنا، سنستخدم console كثيرًا لأنها ممتازة أثناء التعلم والـ debugging.

📌 Conditions

البرنامج أحيانًا يحتاج إلى اتخاذ قرار. مثال: إذا كانت درجة الطالب أكبر من أو تساوي 50: ناجح. وإلا: راسب.

نستخدم: if

let grade = 70;

if (grade >= 50) {
    console.log("Pass");
}

if + else

let grade = 40;

if (grade >= 50) {
    console.log("Pass");
} else {
    console.log("Fail");
}

إذا تحقق الشرط، نفذ الجزء الأول. وإلا، نفذ الجزء الثاني.

else if

عندما يكون لدينا أكثر من احتمال.

let grade = 85;

if (grade >= 90) {
    console.log("Excellent");
} else if (grade >= 75) {
    console.log("Very Good");
} else if (grade >= 50) {
    console.log("Pass");
} else {
    console.log("Fail");
}

هنا البرنامج يفحص الشروط بالترتيب.

⚙️ عاشرًا: Functions

الدالة Function عبارة عن مجموعة من التعليمات نضعها في مكان يمكن استدعاؤه لتنفيذ مهمة معينة.

بدل أن نكرر نفس الكود:

تكرار
console.log("Welcome Ahmed");
console.log("Welcome Ahmed");
console.log("Welcome Ahmed");

يمكننا عمل Function:

function welcome() {
    console.log("Welcome Ahmed");
}

welcome(); // استدعاء الدالة

لماذا Functions؟

  • إعادة استخدام الكود.
  • تنظيم البرنامج.
  • تقليل التكرار.
  • تقسيم البرنامج إلى مهام صغيرة.

📌 Parameter و Argument

function welcome(name) {
    console.log("Welcome " + name);
}

هنا: name يسمى Parameter.

وعندما نستدعي:

welcome("Ahmed");

القيمة: "Ahmed" تسمى Argument.

بمعنى مبسط:
Parameter = المتغير الموجود في تعريف الدالة.
Argument = القيمة التي نرسلها عند استدعاء الدالة.

📌 return

يمكن للدالة أن تنتج قيمة ونرجعها باستخدام return.

function add(a, b) {
    return a + b;
}

let result = add(10, 5);

console.log(result); // 15

هنا الدالة لم تطبع النتيجة مباشرة. هي أعادت النتيجة باستخدام return. ثم خزنا النتيجة في result.

فرق مهم جدًا بين console.log() و return:
console.log تعرض قيمة في الـ Console.
return تعيد قيمة من الدالة إلى المكان الذي استدعاها.

📊 حادي عشر: Arrays

Array تستخدم لتخزين مجموعة من القيم في متغير واحد.

بدون Array
let student1 = "Ahmed";
let student2 = "Ali";
let student3 = "Omar";
مع Array
let students = ["Ahmed", "Ali", "Omar"];

📌 Index

JavaScript تبدأ ترقيم عناصر Array من: 0 — وليس 1.

Ahmed
index = 0
Ali
index = 1
Omar
index = 2
console.log(students[0]); // Ahmed
console.log(students[2]); // Omar

📌 length

يمكننا معرفة عدد عناصر Array باستخدام length.

let students = ["Ahmed", "Ali", "Omar"];

console.log(students.length); // 3
مهم جدًا

آخر index لا يساوي length. إذا كان عندنا 3 عناصر: length = 3 — لكن آخر index: 2 — لأن العد يبدأ من صفر.

🔄 ثاني عشر: while

while تستخدم للتكرار طالما الشرط صحيح.

let count = 1;

while (count <= 5) {
    console.log(count);
    count++;
}
Console Output:
1
2
3
4
5
مهم جدًا

مهم جدًا أن يكون لدينا شيء يؤدي في النهاية إلى توقف الشرط عن أن يكون true.

// ❌ Infinite Loop
let count = 1;

while (count <= 5) {
    console.log(count);
    // count لا يتغير → الشرط سيبقى true للأبد
}

القيمة count لن تتغير. وبالتالي الشرط سيظل: true — وقد يدخل البرنامج في Infinite Loop.

📌 for...of

تستخدم for...of للمرور على عناصر iterable مثل Array.

let students = ["Ahmed", "Ali", "Omar"];

for (let student of students) {
    console.log(student);
}
Console Output:
Ahmed
Ali
Omar

الميزة هنا أننا لا نحتاج أن نتعامل مع الـ index بأنفسنا إذا كان هدفنا فقط المرور على العناصر.

📌 تطبيق شامل على الحصة الأولى

سنفترض أننا نريد برنامجًا بسيطًا يستقبل أسماء الطلاب ويعرض رسالة.

let students = ["Ahmed", "Ali", "Omar"];

for (let student of students) {
    console.log("Welcome " + student);
}

هنا استخدمنا: Variable · Array · for...of · String · Concatenation · console.log()

وهذا هو أسلوبنا في التعلم: لا نحفظ كل مفهوم منفصلًا. بل نربط المفاهيم ببعضها.

🧪 الحصة الثانية من المراجعة

في الحصة الثانية لن نبدأ من الصفر. سنراجع بسرعة ما تعلمناه، ثم نبدأ في ربط المفاهيم.

سنركز على: Conditions · Logical Operators · Functions · Return · Arrays · while · for...of

ثم نبدأ في حل Problems تجمع أكثر من Concept.

Problem 1 Easy

اكتب برنامجًا يحتوي على متغير age. إذا كان العمر أكبر من أو يساوي 16: اطبع You can join. وإلا: اطبع You cannot join.

let age = 16;

if (age >= 16) {
    console.log("You can join.");
} else {
    console.log("You cannot join.");
}
Problem 2 Medium

لدينا درجات الطلاب: [80, 45, 90, 30, 70]. نريد المرور على كل درجة. إذا كانت الدرجة أكبر من أو تساوي 50: اطبع Pass وإلا: اطبع Fail.

الفكرة: Array + for...of + if 
let grades = [80, 45, 90, 30, 70];

for (let grade of grades) {
    if (grade >= 50) {
        console.log("Pass");
    } else {
        console.log("Fail");
    }
}
Problem 3 Easy

نريد Function تستقبل السعر والكمية وتحسب السعر الإجمالي.

function calculateTotal(price, quantity) {
    return price * quantity;
}

let total = calculateTotal(100, 3);

console.log(total); // 300

هنا: price و quantity Parameters. و 100 و 3 Arguments. والنتيجة يتم إرجاعها باستخدام return.

Problem 4 Medium

نريد Function تستقبل درجة الطالب وتعيد "Pass" إذا كانت الدرجة 50 أو أكثر، و "Fail" إذا كانت أقل من 50.

function checkGrade(grade) {
    if (grade >= 50) {
        return "Pass";
    } else {
        return "Fail";
    }
}

let result = checkGrade(75);

console.log(result); // "Pass"

لاحظ أننا بدأنا نربط: Function + Parameter + Condition + return

Problem 5 Medium

نريد المرور على Array من الأرقام وطباعة الأرقام الأكبر من 10 فقط.

let numbers = [5, 12, 8, 20, 3, 15];

for (let number of numbers) {
    if (number > 10) {
        console.log(number);
    }
}
Problem 6 Easy

استخدم while لطباعة الأرقام من 1 إلى 5.

let number = 1;

while (number <= 5) {
    console.log(number);
    number++;
}
Problem 7 Medium

نريد استخدام Logical Operators. إذا كان الطالب عمره 16 سنة أو أكثر، ولديه بطاقة الطالب، يسمح له بالدخول.

let age = 16;
let hasStudentCard = true;

if (age >= 16 && hasStudentCard === true) {
    console.log("Allowed");
} else {
    console.log("Not allowed");
}

هنا استخدمنا: Comparison Operator · Logical AND · if / else · Boolean

Problem شامل Hard

لدينا: ["Ahmed", "Ali", "Omar"]. ونريد Function تستقبل اسم الطالب وتطبع رسالة ترحيب.

let students = [
    "Ahmed",
    "Ali",
    "Omar"
];

function welcomeStudent(name) {
    return "Welcome " + name;
}

for (let student of students) {
    console.log(welcomeStudent(student));
}

هنا جمعنا: Array · for...of · Function · Parameter · Argument · return · String · Concatenation · console.log()

وهذا هو الهدف الحقيقي من المراجعة. ليس أن الطالب يحفظ تعريف كل عنصر بشكل منفصل. ولكن أن يستطيع استخدامهم معًا لحل مشكلة.

  • لماذا كتبنا هذا السطر؟
  • ماذا سيحدث لو غيرناه؟
  • ماذا سيحدث لو حذفناه؟
  • ما نوع البيانات التي نتعامل معها؟

إذا استطعت توقع نتيجة البرنامج قبل تشغيله، فأنت لا تحفظ الكود فقط، بل بدأت تفهم طريقة عمله.
